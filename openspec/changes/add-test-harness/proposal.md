## Why

Скилл — это девять Python-скриптов на ~3700 строк, и ни одной проверки на них нет. Единственное,
что сегодня проверяется автоматически, — разбирается ли код на минимальной версии Python
(`tools/check_compat.py`). Что скрипты делают с логами — не проверяет ничто.

Цена этого видна на любой правке. `parse_logs.py` содержит десятки эвристик: определение формата
построчно, склейка многострочных записей, шаблонизация, извлечение сигнатур. Сигнатуры —
связующая валюта всех трёх контуров: по ним ищет база знаний, по ним локализуется код, они
сохраняются в новую запись. Сдвиг в шаблонизаторе на один символ меняет сигнатуры, а вместе с
ними — попадания в базе знаний и вклад контуров в `confidence.py`. Регрессия при этом выглядит
как обычная работа: скрипт отработал, сводка построена, просто ответ стал другим.

Проверять это вручную нечем: у скилла нет ни одного лога с заранее известным ответом. Каждая
правка проверяется тем, что автор запускает скрипт на случайном логе и глазами смотрит, «похоже
ли». На таком основании нельзя ни принять правку, ни отклонить её.

Отдельно есть режим отказа, который вообще не наблюдаем вручную: **ложная уверенность**. Скилл
обязан говорить «не знаю», когда контуры не сошлись (`confidence-scoring`, `incident-reporting`).
Это требование ничем не проверяется, а нарушается тихо — вывод выглядит увереннее, чем есть, и
именно такой вывод дороже всего обходится: по нему заводят баг на чужую команду.

Все остальные задуманные изменения — работа со временем, очистка персональных данных, учёт
исхода в базе знаний — правят те же скрипты. Без набора тестов каждая из них проверяется
пересказом.

## What Changes

- Появляется **набор фикстур** — логи и разборы с заранее известным ответом. Ответ фиксируется
  рядом с фикстурой: какие сигнатуры должны быть извлечены, какое событие должно быть первым,
  какой сервис — точкой обрыва, какой уровень уверенности допустим.
- Появляется **прогон одной командой**, работающий на голом Python из стандартной библиотеки, без
  установки чего бы то ни было. Скилл не тащит зависимостей — их не тащит и его проверка.
- Проверяется **машиночитаемый вывод**, а не текст для человека. Сравнение идёт по JSON-выводу
  скриптов и по значимым полям, а не по форматированию: тест не должен падать от переставленного
  слова в заголовке.
- Обязательными становятся три класса случаев:
  - **разбор с известным ответом** — скрипты находят то, что заложено в фикстуру;
  - **отсутствие ложных срабатываний** — на логе без инцидента скилл не находит инцидент;
  - **честное «не знаю»** — на данных, где контуры не сходятся, уровень уверенности не
    поднимается выше гипотезы.
- Фикстуры **не содержат реальных данных**: ни персональных, ни секретов, ни внутренних адресов.
  Набор лежит в публичном репозитории, и он же служит примером того, что скилл разрешает
  сохранять.
- Проверка **запускается в CI** на каждый push и pull request, на минимальной поддерживаемой
  версии Python — чтобы заявленная граница версии не протухла.
- Появляется **правило обновления ожидаемого результата**: он меняется вместе с изменением,
  которое его меняет, и это изменение объясняется. Молчаливая перезапись ожидаемого результата
  под текущий вывод скрипта запрещена — так тест перестаёт быть проверкой.

## Capabilities

### New Capabilities

- `test-harness`: набор фикстур с известным ответом, прогон одной командой без внешних
  зависимостей, обязательные классы проверок, правила обновления ожидаемого результата и запуск в
  CI.

## Impact

- `tests/`: новая директория — фикстуры логов и разборов, ожидаемые результаты, прогон.
- `tools/`: `check_compat.py` становится частью общего прогона, а не отдельной командой.
- `.github/workflows/`: запуск прогона на push и pull request.
- `README.md`: раздел о том, как прогнать проверку локально.
- `incident-triage/scripts/*.py`: изменений поведения не требуется; при обнаружении расхождений
  правки идут отдельными изменениями, а не внутри этого.
- Внешних зависимостей не добавляется: прогон работает на стандартной библиотеке.
- Директория `tests/` не входит в состав устанавливаемого скилла и не копируется установщиком.
