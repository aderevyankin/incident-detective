## 4. Прогон на платформах — отложено, вне объёма этого изменения

Прогон требует самих CLI, которых в среде разработки нет, и потому не является задачей
этого изменения: он не выполним здесь и не должен блокировать его завершение. Реестр и
таблица README честно называют непроверенное непроверенным — это и есть поставляемый
результат.

Перечень для будущего прогона (Qwen Code, GigaCode, Claude Code): копирование в
директорию скиллов, самозапуск по описанию инцидента, план работ, вопрос с вариантами,
запуск скриптов, пополнение базы знаний; для GigaCode дополнительно — подтверждение
правила `.qwen/` → `.gigacode/` и имён инструментов. По итогам прогона состояние
правится в реестре и в таблице README.
