## MODIFIED Requirements

### Requirement: Предпроверка окружения до запуска скриптов

Скилл SHALL проверять пригодность окружения одной командой до первого запуска любого
скрипта разбора. Проверка SHALL устанавливать наличие `python3`, его версию, доступность
`git` и является ли текущий каталог git-репозиторием. Скилл SHALL NOT запускать скрипты
контуров, не выполнив предпроверку.

#### Scenario: Проверка выполняется до контуров

- **WHEN** скилл создал план разбора и переходит к работе
- **THEN** он выполняет предпроверку окружения до вызова `kb_search.py`, `parse_logs.py`
  и любого другого скрипта
- **AND** проверка выполняется одной командой, а не серией отдельных вызовов

#### Scenario: Проверка не повторяется в течение разбора

- **WHEN** предпроверка уже выполнена в текущем разборе
- **THEN** перед последующими шагами она не повторяется
- **AND** её результат используется как известный

#### Scenario: Определение версии интерпретатора

- **WHEN** `python3` найден
- **THEN** предпроверка определяет его версию
- **AND** пригодным считается интерпретатор версии 3.8 и выше

#### Scenario: Доступность git фиксируется отдельно

- **WHEN** выполняется предпроверка
- **THEN** отдельно фиксируется наличие `git` и является ли текущий каталог
  git-репозиторием
- **AND** отсутствие любого из двух не признаёт окружение непригодным, а отключает
  только контур кода в части git-истории
