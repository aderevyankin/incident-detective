## Контекст

Изменение документационное: скрипты скилла не трогаются, единственный код — проверка
синхронности `.claude/` ↔ `.qwen/` в прогоне. Главный принцип уже записан в AI_CONTEXT
(«правится существующий раздел, а не добавляется новый»); здесь он доводится до
структуры: у правила один дом.

## Решения

### Выбор канонических домов

Критерий — кто читает документ в момент, когда правило действует:

| Правило | Канон | Почему |
|---|---|---|
| Порядок пути к базе | `references/kb-format.md` | читается при работе с базой |
| Команда предпроверки | `references/limited-mode.md` | это его предмет |
| «Границы» | `SKILL.md` | действуют во время разбора |
| Таблица контуров | `SKILL.md` | README держит копию как витрину, с пометкой |
| Ограниченный режим | `references/limited-mode.md` | SKILL.md — только правило входа |

README остаётся самодостаточным для человека (витринная копия таблицы контуров и сжатые
«Границы» допустимы), но каждая копия помечена ссылкой на канон — читатель и правящий
знают, где источник.

### Проверка .claude ↔ .qwen

В `tests/run.py` — сравнение деревьев `.claude/skills` и `.qwen/skills` по содержимому
файлов (это сегодня побайтовые копии). Для `.claude/commands/opsx/*.md` ↔
`.qwen/commands/opsx-*.toml` сверяется только тело промпта: обёртки форматов разные,
поэтому сравнение — после извлечения текста между маркерами. Падение называет файл.

### Фактические правки

Механические, без решений: `runtime-preflight` в таблицу README (описание — из его
спеки), «шага 6» → «шага 4», `kb-entry-example.md` в перечень, шесть команд `/opsx:*`,
единый вызов `npx @fission-ai/openspec@latest` в обоих документах.

## Риски

- Дельта ложится на `project-documentation`, которую создаёт `add-readme-maintenance`:
  архивировать это изменение можно только после него. Если `add-readme-maintenance`
  отменят, ADDED-требования отсюда переезжают в новую спеку тем же текстом.
- `add-project-presentation` тоже читает README как источник — после замены копий
  ссылками его материал собирается по ссылкам; конфликта нет, но перечитать стоит.
