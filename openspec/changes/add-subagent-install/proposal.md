## Why

Тяжёлый разбор логов съедает контекст основного диалога: выгрузки, промежуточные выводы
парсера и черновые гипотезы остаются в окне, хотя для отчёта нужны только сигнатуры и
итог. Qwen Code и Claude Code поддерживают субагентов — отдельные md-определения с
собственным контекстом, которые ставятся простым копированием файла (`~/.qwen/agents/`,
`~/.claude/agents/` и проектные аналоги). Скилл может выносить разбор логов в такого
субагента, но сегодня не поставляет ни одного определения.

## What Changes

- В составе решения появляется директория `agents/` с определением одного субагента —
  разборщика логов `incident-detective-log-parser`: он получает пути к логам и карточку
  инцидента, запускает скрипты парсинга и возвращает в основной диалог только сжатый
  результат — сигнатуры, счётчики, окна времени, без сырых дампов. Имя несёт префикс
  скилла, чтобы не перетереть чужих агентов, а описание ограничивает применение задачами
  этого скилла.
- Установка субагента — то же копирование, что и у скилла: один файл в директорию агентов
  той платформы и той области (личная/проектная), куда развёрнут скилл. README описывает
  этот шаг рядом с установкой скилла как необязательный; директории агентов каждой
  платформы вносятся в реестр платформ (`add-multi-platform-targets`), для GigaCode — по
  кальке с Qwen Code (`~/.gigacode/agents/`) с пометкой «непроверено».
- `SKILL.md` описывает, когда делегировать разбор субагенту, а когда разбирать в основном
  диалоге (маленький объём, субагент не установлен). Отсутствие субагента не меняет
  результата — только расход контекста.
- Определение субагента пишется в переносимом подмножестве фронтматтера (`name`,
  `description`, при необходимости `tools`), общем для Qwen Code и Claude Code, и
  копируется на все платформы без преобразований.

## Capabilities

### New Capabilities

- `subagent-delegation`: определение субагента-разборщика логов, контракт делегирования
  (что передаётся на вход, что возвращается, что не должно возвращаться), правила выбора
  между субагентом и разбором в основном диалоге, деградация при отсутствии субагента.

### Modified Capabilities

- `skill-packaging`: поставка расширяется директорией `agents/`; установка субагента —
  копирование одного файла в директорию агентов платформы, описанное в документации;
  директории агентов входят в реестр платформ.

## Impact

- Новая директория `agents/` в корне репозитория (вне `incident-detective/`, чтобы не
  уехала в директорию скиллов вместе со скиллом).
- `incident-detective/SKILL.md` — раздел о делегировании разбора.
- `incident-detective/references/platforms.md` — директории агентов по платформам.
- `README.md` — состав поставки и установка субагента копированием файла.
- Зависит от `add-multi-platform-targets`: использует его реестр платформ и допущение о
  GigaCode как кальке с Qwen Code; публичной документации о пользовательских субагентах
  GigaCode не найдено, поэтому для него директория агентов вносится по тому же
  непроверенному допущению и с той же пометкой.
