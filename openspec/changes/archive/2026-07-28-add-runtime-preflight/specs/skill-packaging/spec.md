## MODIFIED Requirements

### Requirement: Требования к окружению скриптов

Скрипты SHALL использовать только стандартную библиотеку Python 3.8 и выше. Скрипты
SHALL NOT требовать сетевого доступа и внешних сервисов. Пригодность окружения SHALL
проверяться в рантайме самим скиллом перед разбором, а не только установщиком, поскольку
скилл может быть развёрнут копированием файлов без запуска установщика.

#### Scenario: Установка зависимостей не требуется

- **WHEN** скрипт запускается на чистой системе с python3
- **THEN** он работает без установки пакетов

#### Scenario: Разбор логов офлайн

- **WHEN** разбираются логи
- **THEN** обработка выполняется локально
- **AND** содержимое логов никуда не отправляется

#### Scenario: Git необязателен

- **WHEN** `git` отсутствует или проект не является репозиторием
- **THEN** относящиеся к git разделы пропускаются, остальной анализ выполняется

#### Scenario: Скилл развёрнут без установщика

- **WHEN** директория скилла скопирована в `~/.qwen/skills/` вручную, без запуска
  `install.sh`
- **THEN** пригодность окружения всё равно проверяется — предпроверкой перед разбором
- **AND** непригодное окружение обнаруживается до запуска скриптов, а не по ходу разбора

#### Scenario: Минимальная версия зафиксирована и проверяема

- **WHEN** проверяется соответствие скриптов заявленной минимальной версии
- **THEN** все запускаемые скрипты разбираются интерпретатором версии 3.8
- **AND** версия 3.8 указана и в документации, и в проверке внутри скриптов

### Requirement: Установка

Скилл SHALL устанавливаться копированием в директорию скиллов Qwen Code — личную или
проектную. Установщик SHALL сохранять существующие записи базы знаний. Установщик SHALL
быть удобством, а не условием работы скилла: скилл, развёрнутый без него, SHALL работать
на тех же правилах.

#### Scenario: Личная установка

- **WHEN** установщик запущен без аргументов
- **THEN** скилл копируется в `~/.qwen/skills/incident-triage`

#### Scenario: Проектная установка

- **WHEN** установщик запущен с `--project`
- **THEN** скилл копируется в `.qwen/skills/incident-triage` текущего проекта
- **AND** может быть закоммичен и роздан команде через git

#### Scenario: Переустановка поверх существующей

- **WHEN** скилл уже установлен и пользователь подтверждает перезапись
- **THEN** записи `INC-*.md` из существующей базы знаний сохраняются и возвращаются
  на место
- **AND** индекс базы пересобирается

#### Scenario: Отсутствие python3

- **WHEN** в системе нет `python3`
- **THEN** установщик сообщает об этом и завершается с ошибкой

#### Scenario: Версия python3 ниже требуемой

- **WHEN** `python3` найден, но его версия ниже 3.8
- **THEN** установщик сообщает найденную и требуемую версию и завершается с ошибкой

#### Scenario: Указания после установки

- **WHEN** установка завершена
- **THEN** выводится напоминание перезапустить Qwen Code, поскольку скиллы читаются
  при старте
- **AND** сообщается путь к базе знаний и способ вынести её наружу через
  `INCIDENT_KB_DIR`
