## MODIFIED Requirements

### Requirement: Установка

Скилл SHALL устанавливаться копированием в директорию скиллов Qwen Code — личную или
проектную. Установщик SHALL сохранять существующие записи базы знаний, пока она лежит
внутри скилла. Замена существующей установки SHALL быть атомарной: прежняя установка не
удаляется, пока новая копия не собрана полностью. В установку SHALL NOT попадать артефакты
разработки (`__pycache__`, `*.pyc`). Установщик SHALL быть удобством, а не условием работы
скилла: скилл, развёрнутый без него, SHALL работать на тех же правилах.

#### Scenario: Личная установка

- **WHEN** установщик запущен без аргументов
- **THEN** скилл копируется в `~/.qwen/skills/incident-detective`

#### Scenario: Проектная установка

- **WHEN** установщик запущен с `--project`
- **THEN** скилл копируется в `.qwen/skills/incident-detective` текущего проекта
- **AND** может быть закоммичен и роздан команде через git

#### Scenario: Переустановка поверх существующей

- **WHEN** скилл уже установлен и пользователь подтверждает перезапись
- **THEN** записи `INC-*.md` из существующей базы знаний сохраняются и возвращаются
  на место
- **AND** индекс базы пересобирается один раз
- **AND** пользователю печатается путь к резервной копии записей

#### Scenario: Сбой во время замены

- **WHEN** копирование новой версии сорвалось — не хватило места или прав
- **THEN** прежняя установка остаётся на месте нетронутой
- **AND** сохранённые записи базы доступны по напечатанному пути

#### Scenario: Чистая поставка

- **WHEN** установка завершена
- **THEN** в установленной директории нет `__pycache__`, `*.pyc` и других артефактов
  разработки

#### Scenario: Неинтерактивная установка

- **WHEN** установщик запущен без TTY — в CI или через конвейер
- **THEN** без флага `--yes` он завершается с понятным объяснением, а не молчаливой
  ошибкой чтения ввода
- **AND** с флагом `--yes` переустановка выполняется без вопросов

#### Scenario: Неизвестный аргумент

- **WHEN** установщик запущен с аргументом, которого не знает
- **THEN** он сообщает об этом и показывает справку, а не выполняет установку по умолчанию

#### Scenario: База знаний вынесена наружу

- **WHEN** база знаний лежит вне директории скилла — по `INCIDENT_KB_DIR` или выбранному
  пользователем пути
- **THEN** переустановка её не затрагивает
- **AND** спасение записей во временную папку для неё не выполняется

#### Scenario: Отсутствие python3

- **WHEN** в системе нет `python3`
- **THEN** установщик сообщает об этом и завершается с ошибкой

#### Scenario: Версия python3 ниже требуемой

- **WHEN** `python3` найден, но его версия ниже 3.8
- **THEN** установщик сообщает найденную и требуемую версию и завершается с ошибкой

#### Scenario: Указания после установки

- **WHEN** установка завершена
- **THEN** выводится напоминание перезапустить Qwen Code, поскольку скиллы читаются
  при старте
- **AND** сообщается путь к базе знаний и способ вынести её наружу через
  `INCIDENT_KB_DIR`
