## ADDED Requirements

### Requirement: Поиск опирается на индекс

Поиск по базе знаний SHALL использовать `index.json` и SHALL читать markdown-файлы записей
только тогда, когда индекса недостаточно — при его отсутствии, устарелости или при выводе
подробностей найденной записи. Сплошное чтение всех файлов базы на каждый запрос
запрещено: база растёт, а поиск вызывается на каждом разборе и должен укладываться в свой
бюджет времени.

#### Scenario: Обычный поиск

- **WHEN** выполняется поиск по тексту или по сигнатурам, а `index.json` актуален
- **THEN** релевантность считается по данным индекса
- **AND** markdown-файлы читаются только для записей, попавших в выдачу

#### Scenario: Индекс отсутствует или устарел

- **WHEN** `index.json` не найден или не соответствует набору файлов базы
- **THEN** поиск выполняется чтением markdown-файлов
- **AND** пользователю сообщается, что индекс стоит пересобрать

#### Scenario: Источник правды не меняется

- **WHEN** данные индекса расходятся с содержимым markdown-файла
- **THEN** правильным считается markdown-файл
- **AND** индекс остаётся производным артефактом
