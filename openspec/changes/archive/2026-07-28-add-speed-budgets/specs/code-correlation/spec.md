## ADDED Requirements

### Requirement: Бюджет обращений к git

Анализ кода SHALL ограничивать число запусков процессов `git`: история запрашивается
пакетно и только по фреймам, попавшим в вывод, а не по каждому фрейму стектрейса. Длинный
стектрейс не должен превращаться в десятки запусков процесса — стоимость запуска процесса
здесь превышает стоимость самой работы git.

#### Scenario: Длинный стектрейс

- **WHEN** стектрейс содержит два десятка фреймов, ведущих в файлы проекта
- **THEN** `git blame` запрашивается только по фреймам, показанным в выводе
- **AND** общее число запусков процессов `git` не превышает бюджет, заданный для скрипта

#### Scenario: Один файл в нескольких фреймах

- **WHEN** несколько фреймов указывают на один и тот же файл
- **THEN** история по файлу запрашивается один раз
- **AND** результат переиспользуется для всех его фреймов

#### Scenario: git отсутствует

- **WHEN** `git` не найден в окружении
- **THEN** разделы истории пропускаются без попыток запуска процессов
- **AND** остальные разделы вывода формируются как обычно
