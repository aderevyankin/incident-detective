## ADDED Requirements

### Requirement: Установка под автономный профиль

Для автономного режима скилл SHALL устанавливаться в **личную** директорию скиллов
платформы, а не в проектную: обвязка разбирает свежий чекаут, а загрузка проектных скиллов
на клиентах семейства Qwen Code пропускается для недоверенной директории. Состояние
проверки этого правила на целевой платформе SHALL быть названо в реестре платформ.

#### Scenario: Установка для обвязки

- **WHEN** скилл разворачивается на машине, где работает автономный разбор
- **THEN** директория `incident-detective/` копируется в личную директорию скиллов
  платформы
- **AND** проектная установка для этого режима не используется

#### Scenario: Правило не подтверждено прогоном

- **WHEN** поведение загрузки проектных скиллов на целевой платформе не проверялось
- **THEN** реестр платформ называет правило предосторожностью с указанием, что прогон не
  выполнялся

### Requirement: Обвязка не входит в поставку скилла

Скилл SHALL оставаться директорией, которую копируют. Приёмник алертов, планировщик и
запуск клиента SHALL NOT входить в состав скилла: поставка не содержит демонов и
установщиков. Документация SHALL приводить команду запуска и состав окружения, которые
обвязка воспроизводит у себя.

#### Scenario: Состав поставки

- **WHEN** пользователь копирует скилл на машину обвязки
- **THEN** в составе только `SKILL.md`, `scripts/`, `references/`, `templates/` и база
  знаний
- **AND** ни планировщика, ни приёмника вебхуков в поставке нет

#### Scenario: Команда запуска описана

- **WHEN** документация описывает автономный режим
- **THEN** она приводит команду запуска клиента с реальными путями к логам и к файлу отчёта
- **AND** называет переменные окружения, которые обвязка обязана задать
