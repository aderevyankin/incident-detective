## ADDED Requirements

### Requirement: Установка описана как получение репозитория и копирование

`README.md` SHALL описывать установку без скрипта установки: получить репозиторий —
клонированием, выгрузкой или передачей ссылки на него своему AI-ассистенту — и
скопировать `incident-detective/` в директорию скиллов платформы. README SHALL NOT
содержать жёсткий URL внутреннего репозитория. README SHALL предупреждать о судьбе
записей базы знаний при обновлении копированием поверх существующей установки.

#### Scenario: Установка без скрипта

- **WHEN** читатель ищет способ установки
- **THEN** README предлагает клонировать репозиторий или дать ссылку на него своему
  AI-ассистенту
- **AND** установка сводится к копированию `incident-detective/` в директорию скиллов
  платформы и перезапуску CLI

#### Scenario: Обновление поверх существующей установки

- **WHEN** README описывает обновление уже установленного скилла
- **THEN** сказано, что копирование затирает базу знаний внутри директории скилла
- **AND** рядом названы способы сохранить записи: внешнее расположение базы или ручное
  сохранение `INC-*.md`
