## ADDED Requirements

### Requirement: Режимы запуска описаны в документации

`README.md` SHALL описывать оба режима работы скилла — диалоговый и автономный — и
границу ответственности между скиллом и средой запуска. Описание автономного режима
SHALL содержать команду запуска с реальными путями, перечень переменных окружения,
которые задаёт обвязка, и путь к файлу отчёта. `AI_CONTEXT.md` SHALL называть автономный
режим среди ограничений и соглашений проекта.

#### Scenario: README описывает автономный режим

- **WHEN** читатель открывает README, не видев скилл раньше
- **THEN** он находит описание запуска от алерта и пример команды с реальными путями
- **AND** видит, где появится файл отчёта и что в нём лежит

#### Scenario: Граница ответственности названа

- **WHEN** README описывает автономный режим
- **THEN** он прямо называет, что запрет действий в этом режиме обеспечивается изоляцией
  процесса, а не подтверждением пользователя
- **AND** называет автономный режим неприменимым там, где изоляции нет

#### Scenario: Непроверенное названо непроверенным

- **WHEN** документация упоминает механизмы ограничения клиента
- **THEN** она различает проверенное прогоном и описанное по документации платформы

#### Scenario: Контекст для агентов обновлён

- **WHEN** в проекте появился автономный режим
- **THEN** `AI_CONTEXT.md` содержит его в разделах раскладки, команд и ограничений
- **AND** новые скрипты названы в раскладке
