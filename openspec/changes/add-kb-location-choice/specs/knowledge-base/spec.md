## ADDED Requirements

### Requirement: Выбор расположения базы знаний при первой записи

Скилл SHALL спрашивать пользователя, где держать базу знаний, когда расположение не задано
явно и выполняется первая запись. Вопрос SHALL задаваться инструментом `ask_user_question`
выбором из готовых вариантов и SHALL NOT требовать ручного ввода пути в вариантах, которые
скилл может составить сам.

#### Scenario: Вопрос при первой записи

- **WHEN** ни `--kb`, ни `INCIDENT_KB_DIR` не заданы и скилл собирается записать в базу
- **THEN** он спрашивает, где хранить базу, до создания записи
- **AND** вопрос задаётся вариантами через `ask_user_question`

#### Scenario: Готовые варианты

- **WHEN** задаётся вопрос о расположении
- **THEN** предлагается вариант «в корне проекта» с уже подставленным путём
- **AND** предлагается вариант «в директории скилла» — текущее поведение по умолчанию
- **AND** свой путь остаётся доступен свободным ответом

#### Scenario: Вопрос не задаётся в начале разбора

- **WHEN** разбор только начался и выполняется поиск по базе знаний
- **THEN** вопрос о расположении не задаётся
- **AND** поиск идёт по той базе, которая доступна сейчас

#### Scenario: Расположение задано явно

- **WHEN** задан `--kb` или `INCIDENT_KB_DIR`
- **THEN** вопрос не задаётся ни при поиске, ни при записи
- **AND** используется заданный путь

#### Scenario: Выбор для этого проекта уже сделан

- **WHEN** расположение не задано явно, но в корне текущего репозитория уже существует база
  знаний
- **THEN** вопрос не задаётся
- **AND** используется база этого репозитория

#### Scenario: В базе внутри скилла уже есть записи

- **WHEN** расположение не задано, но база внутри скилла уже содержит записи
- **THEN** вопрос не задаётся
- **AND** запись идёт туда же, где лежат существующие

#### Scenario: Пользователь отказался выбирать

- **WHEN** пользователь не выбрал расположение
- **THEN** запись идёт в базу внутри скилла
- **AND** в этом разборе вопрос повторно не задаётся

### Requirement: Запоминание выбранного расположения

Скилл SHALL сообщать пользователю, как закрепить выбор через `INCIDENT_KB_DIR`, и
SHALL NOT заводить собственный файл состояния для хранения пути.

#### Scenario: Готовая строка для профиля

- **WHEN** расположение выбрано
- **THEN** скилл показывает готовую строку `export INCIDENT_KB_DIR=<путь>`
- **AND** поясняет, что без неё вопрос возникнет в следующем разборе

#### Scenario: Своего файла состояния нет

- **WHEN** расположение выбрано
- **THEN** скилл не создаёт файлов с настройками ни в проекте, ни в своей директории

#### Scenario: Для базы в проекте строка не обязательна

- **WHEN** выбрана база в корне репозитория
- **THEN** скилл поясняет, что в этом проекте выбор будет прочитан по наличию директории и
  без строки `export`
- **AND** строка показывается как способ работать с этой базой из других директорий

### Requirement: Порядок разрешения пути к базе знаний

Путь к базе знаний SHALL разрешаться в порядке: флаг `--kb`, переменная `INCIDENT_KB_DIR`,
база в корне текущего репозитория при её существовании, база внутри скилла. Существующая
база в корне репозитория SHALL считаться ранее сделанным выбором и SHALL NOT создаваться в
ходе разрешения пути.

#### Scenario: Флаг сильнее всего

- **WHEN** задан `--kb`
- **THEN** используется указанный путь независимо от переменной окружения и от наличия базы
  в репозитории

#### Scenario: Переменная сильнее базы в проекте

- **WHEN** задана `INCIDENT_KB_DIR` и в корне текущего репозитория существует база
- **THEN** используется путь из переменной
- **AND** это остаётся способом намеренно работать с одной базой из разных репозиториев

#### Scenario: База проекта сильнее умолчания

- **WHEN** ни флаг, ни переменная не заданы и в корне текущего репозитория существует база
- **THEN** используется база этого репозитория, а не директория внутри скилла

#### Scenario: Работа с несколькими проектами

- **WHEN** пользователь закрепил `INCIDENT_KB_DIR` для одного проекта и разбирает инцидент в
  другом репозитории, где своя база уже создана
- **THEN** запись идёт в базу того репозитория, в котором ведётся разбор

#### Scenario: Базы в репозитории нет

- **WHEN** ни флаг, ни переменная не заданы и в корне репозитория базы нет
- **THEN** расположение считается невыбранным
- **AND** директория в репозитории при этом не создаётся

#### Scenario: Разбор вне репозитория

- **WHEN** текущая директория не является git-репозиторием
- **THEN** шаг с базой в корне репозитория пропускается
- **AND** разрешение продолжается директорией внутри скилла

#### Scenario: Источник пути известен скиллу

- **WHEN** путь разрешён
- **THEN** скиллу доступно, каким из шагов он получен
- **AND** по этому признаку определяется, задавать ли вопрос о расположении

#### Scenario: Путь записи назван пользователю

- **WHEN** запись добавлена в базу знаний
- **THEN** в ответе назван путь, куда она попала
- **AND** запись в базу репозитория, найденную по третьему шагу, не остаётся незамеченной

### Requirement: Согласие на создание директории базы

Скилл SHALL создавать директорию базы знаний только после выбора пользователя и SHALL
предупреждать о попадании записей в git, когда выбран путь внутри репозитория.

#### Scenario: Директория не создаётся молча

- **WHEN** расположение не выбрано
- **THEN** скилл не создаёт директорию базы ни в проекте, ни в другом месте

#### Scenario: Предупреждение о git

- **WHEN** выбран путь внутри репозитория проекта
- **THEN** скилл одной строкой сообщает, что записи попадут в git и из истории не
  вычищаются
- **AND** продолжает работу, а не отговаривает от выбора

#### Scenario: Путь вне репозитория

- **WHEN** выбран путь вне проекта
- **THEN** предупреждение о git не выводится

## MODIFIED Requirements

### Requirement: Хранение записей в markdown

База знаний SHALL храниться как markdown-файлы, по файлу на инцидент. Файлы SHALL быть
источником правды, а `index.json` — производным артефактом, пересобираемым из них.
Расположение базы SHALL определяться выбором пользователя, а директория внутри скилла
SHALL оставаться значением по умолчанию до того, как выбор сделан.

#### Scenario: Расположение базы

- **WHEN** путь не задан явно и в корне текущего репозитория базы нет
- **THEN** используется директория `kb/` внутри скилла
- **AND** путь переопределяется переменной окружения `INCIDENT_KB_DIR` или флагом `--kb`

#### Scenario: База выбрана в проекте

- **WHEN** путь не задан явно, но в корне текущего репозитория база уже существует
- **THEN** используется она

#### Scenario: Расположение не выбрано

- **WHEN** путь не задан, базы в корне репозитория нет и выбор пользователем ещё не сделан
- **THEN** чтение базы работает с директорией внутри скилла
- **AND** признак «расположение не выбрано» доступен скиллу, чтобы задать вопрос при записи

#### Scenario: Индекс пересобирается

- **WHEN** записи правились вручную и запускается `kb_index.py`
- **THEN** `index.json` перестраивается из markdown-файлов
- **AND** содержит перечень записей, а также сводки по тегам, стендам и сервисам

#### Scenario: Индекс потерян

- **WHEN** `index.json` удалён
- **THEN** поиск по базе продолжает работать
- **AND** индекс восстанавливается пересборкой
