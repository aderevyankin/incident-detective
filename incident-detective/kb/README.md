# База знаний по инцидентам

Записи двух видов: `INC-*.md` — разбор одного инцидента, `SRC-*.md` — карта источников
логов для пары «стенд + сервис». `index.json` генерируется скриптом и в редактировании не
нуждается.

Источник правды — markdown: правится руками, читается человеком, кладётся в git.

- Добавить/дополнить: `python3 ../scripts/kb_add.py --help`
- Найти: `python3 ../scripts/kb_search.py "симптом"`
- Пересобрать индекс после ручных правок: `python3 ../scripts/kb_index.py`
- Формат записи: [../references/kb-format.md](../references/kb-format.md)
- Заполненный пример: [../templates/kb-entry-example.md](../templates/kb-entry-example.md)

Эта директория — база **по умолчанию**, до того как расположение выбрано. При первой
записи скилл спросит, где её держать: в корне проекта (`memory/knowledgebase/`), здесь
или по своему пути. Пока здесь нет ни одной `INC-*.md`, выбор считается несделанным.

Закрепить выбор (например, репозиторий команды):

```bash
export INCIDENT_KB_DIR=/path/to/team/incidents
```

Порядок разрешения пути и последствия выбора «в проект» —
[../references/kb-format.md](../references/kb-format.md).

Секреты и персональные данные в базу не попадают: `kb_add.py` вычищает очевидные
токены и пароли, но полагаться только на это не стоит — сырые дампы логов сюда
класть не надо в принципе.
